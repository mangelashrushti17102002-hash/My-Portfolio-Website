# 🌐 Personal Portfolio Website

A modern, responsive personal portfolio website built using HTML, CSS, and JavaScript to showcase my skills, projects, services, and professional profile as a Data Analyst and Web Developer.

## ✨ Features

- Modern dark-themed design with interactive hover effects.
- Home section with animated text highlighting my professional roles.
- About Me section with education and personal information.
- Skills section showcasing technical skills and proficiency levels.
- Services section highlighting data analytics, web development, dashboard design, SQL, UI design, and automation.
- Projects section featuring my portfolio, Zepto Retail Analysis, Telco Churn Analysis, and Pill Tracker projects.
- Downloadable resume and social media links.
- Contact section with email, LinkedIn, and GitHub links.
- Responsive grid layouts for project cards, skills, and services.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, layouts, and hover effects
- JavaScript – Interactive features
- Typed.js – Animated typing effect
- Font Awesome – Icons
- Google Fonts (Poppins) – Typography

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.
